# Desktop interaction prototypes

These are illustrative, independent wireframes, not the application. Download a standalone HTML file to open it in a browser. GitHub displays source rather than hosting these as a live site. External preview libraries may need internet access. All files start with default sample content; live account data and interaction snapshots are not included. Preview state does not implement production saving, sharing, AI, or cross-screen transfer.
