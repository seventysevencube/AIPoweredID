# Original Project Brief

Initial user request, lightly normalized for Markdown. This is historical context; subsequent discussion refined and superseded parts of the scope.

The user is an instructional designer seeking an AI agent that provides survey-like forms to progress through ADDIE. After the designer submits a form, AI uses the responses to create a starting point for the next stage. The user requested brainstorming, requirements clarification, and an accessible UI before building.

## Initial workflow

1. Complete an Analysis form covering the gap, audience, stakeholders, and constraints.
2. Use the results to seed a Design form covering learning objectives, assessments, an objective–assessment matrix, and delivery method.
3. Refine Design with guidance checklists, linked instructional-design resources, and optional brain-break activities during cognitively demanding review.
4. Recommend collaboration/peer review where useful and create a shareable link at the designer's request.
5. Optionally invite reflection on AI output, level of AI contribution, output preferences, and additional resources.
6. Produce a detailed Design plan and content map using designer-provided documents, internet sources, or the designer's choice of source approach.
7. Repeat review, optional collaboration, and optional reflection.
8. Produce storyboards, scripts, and job-aid/performance-support requirements aligned with the reviewed plan.

The user explicitly wanted to settle requirements and UI before starting development.
